Compound Inequalities

A compound inequality joins two conditions with AND or OR. AND keeps only values both conditions agree on — a bounded stretch of the line. OR keeps values either condition allows — everything outside a gap.

Build one

−4 < x < 5

Worked example

  1. −3 ≤ 2x − 1 < 5
  2. −3 + 1 ≤ 2x < 5 + 1   (add 1 to all three parts)
  3. −2 ≤ 2x < 6
  4. −1 ≤ x < 3   (divide all three parts by 2)
CHAPTER 2 / 3

Quadratic Inequalities

A quadratic inequality asks where a parabola sits above or below the x-axis. Factor it, find the roots, then test the sign in each region they create — the roots are the only places the sign can flip.

Pick an example

(x − 3)(x + 2) > 0

Roots split the line into three pieces. On each piece the sign of the whole expression stays constant — so pick one test point per piece and see if it satisfies the inequality.

Solution: x < −2 or x > 3
